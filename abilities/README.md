Starts empty on a fresh project. Real `ability-*.md` files land here once at least one Role needs a named capability to point at — see `templates/abilities.md` for the format, and `examples/sample-business/abilities/` for a filled-in example.

Several of the kit's shipped `skills/*` (`review-before-shipping`, `verify-locally-and-remotely`, `merge-safely`, `feedback-to-fix`, `deploy-and-verify`) already carry `grounded-in: [ability-release-readiness]` — pointing at an Ability name that doesn't exist here yet. That's the same `orphan-pending` state a Skill can legitimately sit in before its Ability is written (see `docs/SCHEMA.md`). Create your own `ability-release-readiness.md` here (or rename the pointer) once `roles/role-reviewer.md` exists and needs a named capability — don't leave it orphaned indefinitely once a real Role is asking for it.
