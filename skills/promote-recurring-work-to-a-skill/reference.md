# Promote Recurring Work to a Skill — reference

## The evidence this rule is built from

No single source states "extract a skill after N occurrences" as one formal, numeric principle. What actually happens, checked directly against the source material's own skills library history rather than inferred:

- **Told directly, fires on the first run.** After a live pass through a batch of meeting transcripts, the direct instruction was: "Now look back at what you just did and build a skill for it." No repetition involved — being asked was the whole trigger.
- **Two occurrences, same session-crossing pattern.** One skill's own history states plainly it was "extracted after [the same question was asked] in near-identical words across two sessions."
- **At least three occurrences over three weeks**, for a different skill — its own genesis note names this explicitly as the number of times the same failure recurred before the skill was written down.
- **A single costly incident, named as the exception to the norm.** One skill's own status line states it was "extracted... first named after a single real incident... rather than a repeated pattern across sessions" — explicitly flagging that a one-off extraction is the unusual case, not the default.

## Why this is worth its own skill rather than just a line in AGENTS.md

The pattern above is easy to know about and still not do — recognizing "this is the second time" requires actually checking, in the moment, rather than trusting a feeling that something seems familiar. Naming it as an invocable skill gives it the same forced-check treatment `AGENTS.md`'s tripwire rule gives corrections, extended to the question "does this correction/task need to become more than a log line."

## Relationship to the tripwire in AGENTS.md

The tripwire (2nd same-category `fix` entry forces an edit) and this skill are not the same mechanism. The tripwire's forced action is *editing an existing rule* — often enough on its own for a single constraint. This skill is for when the recurring thing is a *procedure* (multiple steps, in a specific order, with real judgment calls along the way) that a single added sentence in `AGENTS.md` can't actually carry.
