# Start of session

1. Read `AGENTS.md` if you haven't this session.
2. Read `STATE.md` — what's done, next, blocked.
3. Skim `docs/index.json` (run `npm run index` first if it looks older than the last few commits) and `decisions/` for anything relevant to what you're about to do. Cite an existing decision rather than re-deriving it.
4. If `lessons.md` hasn't been updated in a while relative to how much has actually happened, say so before proceeding — don't assume a quiet log means nothing went wrong (see `AGENTS.md` § "The learning loop," point 4).
5. **If this session might be resuming after an interruption** (a limit hit, an outage, a crash — not a normal, deliberate session-end), don't trust any summary of what happened before it. Run `skills/check-repo-sync/SKILL.md`, and reconcile it against `STATE.md`/`HANDOFF.md` before touching anything, per `AGENTS.md` § "Surviving a limit hit, an outage, or a crash."
