# Start here

Before anything else, answer one question: **is this a new, clean project — or does code already exist?**

- **New, clean project** (nothing built yet, or a truly empty repo) → run `prompts/setup-new-project.md`.
- **Existing project** (anything already built — including a messy Lovable/Bolt/Replit/v0 export with no clear structure) → run `prompts/restructure-existing.md`.

Don't guess which one applies — if there's any real code, data, or configuration already in the project, treat it as existing, even if it's small or rough. Both prompts open with the same 5 plain-language business questions; the existing-project path adds a mandatory, complete inventory of what's already there (`skills/mirror-then-integrate/SKILL.md`) before proposing anything, precisely because guessing at what "already exists" covers is the mistake this kit exists to prevent.
