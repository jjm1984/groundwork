# dec-003: Feedback channel and hosting

## Context

Ran `skills/set-up-collaboration-channel/SKILL.md` per `prompts/setup-new-project.md` step 5, after the business questions (`dec-001`, `dec-002`).

## Options considered

Per `docs/collaboration-and-hosting-options.md` § A: repo inbox, GitHub Issues, a Drive folder, a shared doc, an in-product widget.

## Decision

GitHub Issues for feedback (Dave's brother-in-law files bugs there already when helping out); no Drive folder for now — nobody involved is chat-only/repo-less. Hosting: Bolt's own built-in deploy stays as-is, no change.

## Why

Zero additional setup, and the one other person who reports issues already has GitHub access. Revisit if a non-technical collaborator (Dave's bookkeeper, floated as a future helper) ever needs to leave feedback without a GitHub account — that's the trigger for adding a Drive folder, not a fixed date.
