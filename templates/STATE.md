# State

*Living document — this is what an agent reads first, every session. Keep it current; a stale STATE.md is worse than none, because it gets trusted.*

## Done

- What's actually finished, most recent first. A one-line summary and, if useful, a pointer to the decision record that covers it.

## Next

- What's being worked on or about to be. If it's genuinely undecided how to approach it, say that here rather than in Done.

## Blocked

- What's stuck, and on what — a person, a decision, an external dependency. If nothing is blocked, delete this section rather than leaving it empty as a placeholder.

## Not doing, on purpose

- Anything explicitly rejected, so nobody re-proposes it without knowing it was already considered and turned down. One line: what, and why.
